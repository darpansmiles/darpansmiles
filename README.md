## Featured: Grounded

A reference build for **governed data agents**. Instead of letting a model write unrestricted SQL, the agent routes one declared tool call to a governed metric. The platform resolves it, enforces policy, verifies the result, records an audit event, and returns a lineage citation. That makes a fabricated numeric answer **structurally unavailable at the execution boundary**. Model quality still matters for routing and coverage, but not for whether the number is real.

**Measured:** across five dataset packs and up to nine local models, every completed governed comparison recorded **0% hallucination** and 100% correct-when-answered, against an ungoverned baseline that fabricated or produced non-executable SQL most of the time, with confidence intervals and exact McNemar tests reported, not just point estimates.

## What I work on

- **Data movement infrastructure.** Batch, CDC, streaming, and metadata pipelines across databases, warehouses, lakehouses, APIs, messaging, and object storage.
- **Query acceleration.** In-memory analytical engines with concurrency limits and cloud-cost guardrails.
- **Metadata, lineage, and governance.** Knowledge graphs, catalogs, and the contracts that let platform layers evolve without breaking each other.
- **Agent-ready data platforms.** Semantic layers and MCP surfaces that give agents consistent, governed business definitions instead of raw tables.
- **Evaluation for data agents.** Failure taxonomies, hallucination and schema-break rates, distributions over averages.
- **Product quality and economics.** Multi-dimension quality models, release sign-off, and cost benchmarking that holds up in a customer evaluation.
