## Featured: Grounded

A reference build for **governed data agents**. Instead of letting a model write unrestricted SQL, the agent routes one declared tool call to a governed metric; the platform resolves it, enforces policy, verifies the result, records an audit event, and returns a lineage citation. That makes a fabricated numeric answer **structurally unavailable at the execution boundary** — model quality still matters for routing and coverage, but not for whether the number is real.

**Measured:** across five dataset packs and up to nine local models, every completed governed comparison recorded **0% hallucination** and 100% correct-when-answered, versus an ungoverned baseline that fabricated or produced non-executable SQL most of the time — with confidence intervals and exact McNemar tests reported, not just point estimates.
